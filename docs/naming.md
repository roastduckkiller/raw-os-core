# Raw OS Naming

Use these names consistently:

- Product / concept: `Raw OS`
- Repository / package / directory: `raw-os`
- CLI wrapper: `scripts/raw-os`
- Schema and event prefixes: `raw-os-*`

Do not use:

- `rawOS`
- `RAW OS`
- `RawOS`

## Meaning

Raw OS is not an operating system kernel.

It is an evidence operating substrate for agent runtimes: a layer that captures
normalized events, assets, delivery evidence, append-only ledgers, rendered raw
outputs, and audits.

## Short Description

Use this sentence in public docs:

```text
Raw OS is an evidence operating substrate for agent runtimes.
```

If extra clarification is needed:

```text
Raw OS is not an operating system kernel. It is an evidence operating substrate
for agent runtimes.
```
